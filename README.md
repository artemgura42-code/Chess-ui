# CHESS VISION

Android chess analysis application.

## Current version
0.1.0

## Technology
- Kotlin
- Jetpack Compose
- Stockfish 10 planned
- Lichess integration planned

## Build
Run `gradle assembleDebug`.

APK output:
`app/build/outputs/apk/debug/app-debug.apk`

External engine analysis is intended for completed games,
training positions and games against Lichess AI.
